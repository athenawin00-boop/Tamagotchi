# 캐릭터 다마고치

지금 대화 중인 캐릭터를 다마고치처럼 돌보는 실리태번(SillyTavern) 확장입니다.
캐릭터 아바타가 작은 창에 나타나고, 밥을 주거나 놀아 주면 캐릭터가 자기 말투로 한마디씩 반응합니다.

## 설치

실리태번 → 확장(블록 아이콘) → **확장 설치** → 이 저장소 주소를 붙여넣기.

## 사용법

| 어디서 | 무엇을 |
|---|---|
| 입력창 옆 🥚 버튼 | 창 열기/닫기. 돌봐야 할 때 빨간 점이 떠요 |
| 마법봉 메뉴 → 캐릭터 다마고치 | 창 열기/닫기 |
| 처음 열면 | 알 상태예요. **알 깨우기**를 누르면 태어나요 |
| 돌봄 버튼 | 밥 · 놀기 · 재우기/깨우기 · 씻기 · 약(아플 때) |
| 애정 버튼 | 쓰담 · 손잡기(친밀도 20) · 포옹(40) · 뽀뽀(60) · 선물. 🔒는 친밀도가 차면 열려요 |
| 선물 | 하루 3개. 캐릭터마다 좋아하는 것·싫어하는 것이 달라요(카드를 읽고 정해요). 줘 보면 ♥/✓/✕ 표시가 남아요 |
| 아바타 클릭 | 쓰다듬기 |
| 말 걸기 칸 | 하고 싶은 말을 적으면 캐릭터가 대답해요 |
| 머리줄 | 끌어서 옮기기(PC), 오른쪽 아래 모서리로 크기 조절 |
| ⚙ | 설정을 창 안에서 바로 열기 |
| `/tama` | 상태 보기. `/tama feed`, `/tama talk 안녕`, `/tama show` 등 |

### 수치

포만감 · 기분 · 에너지 · 청결 · 친밀도 다섯 가지예요. 실제 시간이 지나면 줄어들고, 실리태번을 꺼 둔 동안에도 (설정한 최대 시간까지) 줄어듭니다.
포만감이나 청결이 0이 되면 아파요. 약을 주면 낫습니다. 자는 동안엔 에너지가 차고, 다 차면 스스로 일어나요.
친밀도는 돌봐 줄수록 오르고(같은 행동은 5분에 한 번만 반영), 방치하면 조금씩 줄어요.
### 관계

친밀도가 오르면 관계 단계가 **낯가림 → 호감 → 썸 → 연인 → 천생연분**으로 바뀌고, 단계가 오르는 순간 캐릭터가 특별한 한마디를 해요.
3시간 넘게 비웠다 돌아오면 캐릭터가 먼저 말을 걸어요. 하루 넘게 비우면 서운해합니다.

펫은 **캐릭터마다 따로** 저장되고, 같은 캐릭터라면 어떤 채팅을 열어도 이어집니다.

## 스프라이트(캐릭터 그림)

그림 묶음을 넣으면 아바타 대신 상태·행동에 맞는 그림이 나옵니다.
캐릭터 채팅을 연 상태에서 설정 → **스프라이트 → ZIP 올리기**. `characters/캐릭터이름/tama/`에 저장돼요.

| 파일 이름 | 언제 나오나 |
|---|---|
| `idle-1.png` … | 평소(20초마다 번갈아). 친밀도 60 이상이면 love도 섞여요 |
| `happy` | 기분이 아주 좋을 때, 씻긴 뒤, 약 먹고 나은 뒤, 태어날 때 |
| `love` / `shy` | 쓰다듬기 / 말 걸기 |
| `eat` / `full` | 밥 / 배불러서 거절 |
| `play` / `wake` | 놀기 / 잘 자고 일어남 |
| `surprised` / `pout` | 안 아픈데 약 줌 / 시무룩·꼬질꼬질·덜 자고 깸 |
| `hungry` / `sleepy` / `sick` / `sleep` | 배고픔 / 졸림 / 아픔 / 자는 중 |
| `hand` / `hug` / `kiss` | 손잡기 / 포옹 / 뽀뽀 (없으면 shy·love로 대신) |
| `gift` / `wave` | 선물 받음 / 오랜만에 돌아왔을 때 (없으면 happy로 대신) |

- 같은 상태가 여러 장이면 `eat-1`, `eat-2`처럼 번호를 붙여요. 그중 하나가 무작위로 나와요.
- 없는 상태는 비슷한 그림으로 대신해요(예: full이 없으면 happy → idle).
- **옷**: `hoodie_eat-1.png`처럼 `옷이름_상태`로 넣으면 👕 버튼이 생겨요. 옷에 없는 상태는 기본 그림으로 나와요.
- png, webp, gif 모두 됩니다. 배경은 투명하게.

## 설정

| 항목 | 설명 |
|---|---|
| 캐릭터 반응 | 행동할 때 모델로 캐릭터 대사를 만들어요. 끄면 기본 대사를 씁니다 |
| 연결 프로필 | 반응에 쓸 모델(비우면 지금 연결된 모델). 가벼운 모델을 따로 지정하면 좋아요 |
| 최대 토큰 / 반응 언어 | 추론 모델이 빈 답을 주면 최대 토큰을 올려 주세요 |
| 컨디션을 답장에 반영 | 지금 상태(배고픔, 졸림 등)를 본 대화 답장에 살짝 알려 줘요 |
| 대화하면 친밀도 오르기 | AI 답장이 올 때마다 기분과 친밀도가 조금 올라요(하루 최대 +5) |
| 오랜만에 오면 먼저 말 걸기 | 3시간 이상 비웠다 돌아오면 반응해요(모델 호출 1회) |
| 연애 모드 | 끄면 단계가 아는 사이 → 친한 사이 → 단짝으로 바뀌고 뽀뽀가 빠져요 |
| 줄어드는 속도 | 멈춤 · 느리게 · 보통 · 빠르게 |
| 꺼 둔 동안 최대 반영 시간 | 오래 비워도 이 시간만큼만 줄어들어요 |
| 알림 / 창 불투명도 | 흐리게 해 둬도 마우스를 올리면 선명해져요 |
| 처음부터 키우기 | 지금 캐릭터의 기록을 지우고 알부터 다시 |

그룹 채팅에서는 쉬어요(1:1 채팅에서만 동작).
